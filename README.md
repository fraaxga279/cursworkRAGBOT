# Telegram-бот по ПОПАТКУС НИУ ВШЭ

Чат-бот для ответов на вопросы по ПОПАТКУС НИУ ВШЭ
проект реализован локально в состоянии mvp

## работа

1. Текст PDF извлекается, очищается и разбивается на фрагменты.
2. Модель `multilingual-e5-small` преобразует фрагменты в векторы, которые сохраняются в ChromaDB.
3. Retriever находит фрагменты, близкие по смыслу к вопросу пользователя.
4. Generator передаёт вопрос и найденный контекст в `gpt-4o-mini` для формирования ответа.

## запуск
работает на python 3.12

```bash
python -m pip install -r requirements.txt
```
сам документ скрыт поэтому для запуска нужно скачать указанную версию с официального сайта НИУ ВШЭ и разместить тут

```text
data/raw/popatkus.pdf
```
дальше подключить свои ключи бота и ллм (в проекте используется модель от OpenAi)
```dotenv
TELEGRAM_BOT_TOKEN=
OPENAI_API_KEY=
```

далее при первом запуске обработать документ и сохранить разбиение в бд (можно один раз при первом запуске)
```bash
python -m scripts.build_chunks
python -m scripts.build_index
```
и потом запуск:
```bash
python -m scripts.run_bot
```

## по структуре:

- `src/data_processing/` — извлечение, очистка и разбиение текста.
- `src/retrieval/` — эмбеддинги и поиск фрагментов.
- `src/generation/` — промпты и генерация ответов.
- `src/bot/` — Telegram-интерфейс и RAG-сервис.
- `src/evaluation/` — оценка качества поиска и ответов.
- `scripts/` — скрипты подготовки данных, запуска и экспериментов.
- `data/test/` — тестовый набор вопросов.
- `config.yaml` — настройки проекта.

## по ограничениям
- как было указано в начале проект не доделан до общегодоступного бота и запускается локально
- параметры для работы бота (модель эмбеддинга, параметры чанкирования) были подобраны исходя из результатов проведенных экспериментов (в тексте курсовой работы)
- все что отвечает бот нужно перепроверять
- бота можно улучшить, проводя доп эксперименты и отслеживая метрики
